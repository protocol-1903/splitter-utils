This mod is the splitter variant of [Loader Utils](https://mods.factorio.com/mod/loader-utils), which adds custom variants of each splitter that can be chosen during gameplay as desired.

![showcase](https://github.com/protocol-1903/web-host-things/blob/aba2db9f6ff2219b3a09e233bfd13d01831c0364/splitter-utils.gif?raw=true)

# Modes

![exchange input lines example](https://github.com/protocol-1903/web-host-things/blob/c3911886bdbe7b934151c0da38ccf0f2f7251167/splitter%20utils%20input%20exchange.png?raw=true)

Exchange input lines swaps the two internal lanes of a splitter input. So the inner left lane becomes the inner right lane and vice versa, then normal splitter mechanics are applied and See above examples.

![exchange output lines example](https://github.com/protocol-1903/web-host-things/blob/c3911886bdbe7b934151c0da38ccf0f2f7251167/splitter%20utils%20output%20exchange.png?raw=true)

Exchange output lines swaps the two internal lanes of a splitter output. So what would normally be the inner left lane after normal splitter logic is now the inner right lane, and vice versa. See above examples.

# Compatibility
These changes are done to all splitters in the game. This mod does not add any splitters for the player to use, but edits existing ones. This process is automatic, meaning it should be compatible with mods, but also means it has the chance to break. Let me know if any issues crop up, or if you have any features you wish to be added. [MOD DEVS] If you wish for splitters to be ignored, add `prototype.ignore_by_splitter_utils = true` and no changes will be made.

My mods are made 100% by humans, with no computer generated code or graphics.
If you have a mod idea, let me know and I can look into it.
